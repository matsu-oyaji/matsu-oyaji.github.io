# お知らせ管理ガイド

このガイドでは、サイトのお知らせ機能の使い方を詳しく説明します。お知らせは自動的にトップページと一覧ページに表示される重要な機能です。

## 🎯 お知らせシステムの概要

### 🔄 お知らせの表示フロー

```mermaid
flowchart TD
    A[📝 お知らせファイル作成<br/>announcements/] --> B[🏠 トップページ<br/>最新1件自動表示]
    A --> C[📋 お知らせ一覧<br/>全件表示]
    A --> D[📄 個別ページ<br/>詳細表示]
    
    B --> E[👥 訪問者が閲覧]
    C --> E
    D --> E
    
    style A fill:#e1f5fe
    style B fill:#e8f5e8
    style C fill:#fff3e0
    style D fill:#f3e5f5
```

### 📍 表示場所と特徴

| 表示場所 | 件数 | 内容 | 用途 |
|----------|------|------|------|
| 🏠 **トップページ** | 最新1件 | タイトル + 概要 | 最新情報の告知 |
| 📋 **お知らせ一覧** | 全件 | タイトル + 概要 | 過去の履歴確認 |
| 📄 **個別ページ** | 1件 | 完全な内容 | 詳細情報の確認 |

## 📁 ファイル構成と命名規則

### 🗂️ 保存場所
```
announcements/
├── 20250801_natsu-matsuri-info.md      # 夏祭り情報
├── 20250301_member-recruitment.md      # 会員募集
├── 20250610_volunteer-work.md          # ボランティア募集
└── 20250915_autumn-event.md           # 秋イベント（新規作成例）
```

### 📝 ファイル命名規則

**パターン**: `YYYYMMDD_<内容キーワード>.md`

**良い例**:
```
20250801_natsu-matsuri-info.md       # 夏祭り情報
20250301_member-recruitment.md       # 会員募集  
20250415_event-cancel.md             # イベント中止
20250520_cleanup-volunteer.md       # 清掃ボランティア
20250701_pta-meeting.md              # PTA会議案内
```

**避けるべき例**:
```
announcement.md                      # 日付なし
2025-08-01_info.md                  # ハイフン使用
お知らせ.md                          # 日本語
20250801 event.md                   # 空白あり
```

## 📄 お知らせファイルの構造

### 🔧 基本構造

```markdown
---
date: YYYY-MM-DD          # お知らせの日付
time: "HH:MM"            # 時刻（オプション）
title: "お知らせのタイトル"   # お知らせのタイトル
type: "warning"          # お知らせの種類
priority: 1              # 優先度（同日内での順序）
visible: true            # 表示制御（オプション）
---

# お知らせのタイトル

お知らせの本文をここに記載します。

<!-- more -->

## 詳細情報

`<!-- more -->` より下の内容は詳細ページでのみ表示されます。
```

### 🏷️ お知らせの種類（type）

```mermaid
graph TD
    A[お知らせの種類] --> B[🚨 warning<br/>重要な警告]
    A --> C[📢 info<br/>一般情報]  
    A --> D[🎉 tip<br/>良いニュース]
    A --> E[⚠️ danger<br/>緊急警告]
    
    B --> B1[オレンジ色<br/>イベント中止など]
    C --> C1[青色<br/>一般的なお知らせ]
    D --> D1[緑色<br/>イベント告知など]
    E --> E1[赤色<br/>緊急事態]
    
    style B fill:#fff3cd
    style C fill:#d1ecf1
    style D fill:#d4edda
    style E fill:#f8d7da
```

| タイプ | 色 | アイコン | 使用例 |
|--------|---|----------|--------|
| `warning` | 🟠 オレンジ | 🚨 | イベント中止、延期、重要変更 |
| `info` | 🔵 青 | 📢 | 一般的なお知らせ、案内 |
| `tip` | 🟢 緑 | 🎉 | イベント告知、良いニュース |
| `danger` | 🔴 赤 | ⚠️ | 緊急事態、至急対応必要 |

### 📊 優先度（priority）

同じ日付に複数のお知らせがある場合の表示順序を制御：

```mermaid
graph LR
    A[同じ日付の複数お知らせ] --> B[priority: 1<br/>最優先]
    A --> C[priority: 2<br/>2番目]
    A --> D[priority: 3<br/>3番目]
    
    style B fill:#ffebee
    style C fill:#f3e5f5
    style D fill:#e8eaf6
```

**例**:
```yaml
# 2025年8月1日のお知らせ複数件
---
date: 2025-08-01
title: "緊急：台風による夏祭り中止"
type: "danger"
priority: 1        # 最上位表示
---

---
date: 2025-08-01  
title: "夏祭り代替イベントのお知らせ"
type: "info"
priority: 2        # 2番目に表示
---
```

### 👁️ 表示制御（visible）

```mermaid
flowchart TD
    A[visible設定] --> B[true<br/>デフォルト]
    A --> C[false<br/>非表示]
    
    B --> B1[トップページ: ✅表示]
    B --> B2[一覧ページ: ✅表示]  
    B --> B3[個別ページ: ✅表示]
    
    C --> C1[トップページ: ❌非表示]
    C --> C2[一覧ページ: ❌非表示]
    C --> C3[個別ページ: ✅表示]
    
    style B fill:#e8f5e8
    style C fill:#ffe6e6
```

**用途例**:
- 📝 **下書き**: 作成中だが公開前
- 📚 **アーカイブ**: 過去の記録として保管
- 🧪 **テスト**: 動作確認用のサンプル

## ✍️ お知らせ作成の実践

### 🆕 新規お知らせの作成

**手順**:

```mermaid
flowchart TD
    A[1️⃣ ファイル名を決定] --> B[2️⃣ ファイル作成]
    B --> C[3️⃣ YAMLヘッダー記述]
    C --> D[4️⃣ 本文作成]
    D --> E[5️⃣ ローカル確認]
    E --> F[6️⃣ GitHubにアップロード]
    
    style A fill:#e1f5fe
    style F fill:#e8f5e8
```

**実際の作成例**:

1. **ファイル作成**
   ```
   announcements/20250915_autumn-festival.md
   ```

2. **内容記述**
   ```markdown
   ---
   date: 2025-09-15
   time: "10:00"
   title: "秋祭り開催のお知らせ"
   type: "tip"
   priority: 1
   ---

   # 🍂 秋祭り開催のお知らせ

   10月20日（日）に恒例の秋祭りを開催いたします！
   今年も楽しい企画をたくさん用意してお待ちしています。

   <!-- more -->

   ## 📅 開催概要

   - **日時**: 10月20日（日）10:00〜15:00
   - **場所**: 松ケ丘小学校 校庭
   - **参加費**: 無料
   - **雨天**: 体育館で開催

   ## 🎪 イベント内容

   ### 午前の部（10:00〜12:00）
   - 🏃‍♂️ 親子リレー
   - 🎯 射的ゲーム
   - 🍭 綿あめ作り体験

   ### 午後の部（13:00〜15:00）
   - 🎤 のど自慢大会
   - 🍜 焼きそば・たこ焼き販売
   - 🎁 お楽しみ抽選会

   ## 📞 お問い合わせ

   不明な点がございましたら、おやじの会までお気軽にお声がけください。

   皆様のご参加を心よりお待ちしております！
   ```

### ✏️ 既存お知らせの編集

**編集手順**:
1. VS Code で該当ファイルを開く
2. 内容を修正
3. 保存（`Ctrl + S`）
4. ローカルで確認
5. GitHubにアップロード

**よくある編集パターン**:

| 編集内容 | 修正場所 | 例 |
|----------|----------|---|
| 日時変更 | YAMLの`date`, `time` | `date: 2025-10-25` |
| タイトル変更 | YAMLの`title`と本文 | `title: "秋祭り延期のお知らせ"` |
| 緊急度変更 | YAMLの`type` | `type: "warning"` |
| 内容追加 | 本文セクション | 新しい見出しと内容を追加 |

### 🗑️ お知らせの削除

**削除方法**:

```mermaid
flowchart TD
    A[お知らせ削除の判断] --> B{完全削除?}
    B -->|Yes| C[ファイルを削除]
    B -->|No| D[visible: false に変更]
    
    C --> E[GitHubにコミット]
    D --> E
    E --> F[自動的に非表示]
    
    style C fill:#ffebee
    style D fill:#fff3e0
```

**完全削除**:
```bash
# ファイルを削除
rm announcements/20250801_old-announcement.md

# 変更をコミット
git add .
git commit -m "古いお知らせを削除"
git push
```

**非表示（推奨）**:
```yaml
---
date: 2025-08-01
title: "古いお知らせ"
type: "info"
visible: false    # 一覧からは非表示、URLアクセスは可能
---
```

## 🎨 高度な機能

### 📝 概要と詳細の分割

`<!-- more -->` マーカーを使用して、概要部分と詳細部分を分けることができます：

```markdown
---
date: 2025-09-15
title: "イベントのお知らせ"
type: "tip"
---

# イベントのお知らせ

10月にイベントを開催します！

詳細は以下をご確認ください。

<!-- more -->

## 詳細情報

ここから下は詳細ページでのみ表示されます。

### 会場詳細
- 住所: 〒xxx-xxxx ...
- アクセス: ...

### 注意事項
- 持ち物: ...
- 服装: ...
```

**表示の違い**:
- **トップページ/一覧**: `<!-- more -->` より上のみ表示 + 「続きを読む」リンク
- **詳細ページ**: 全内容を表示

### 🔗 内部リンクの活用

```markdown
# 関連情報

詳しくは以下のページもご覧ください：

- [活動内容について](/activities)
- [お問い合わせ](/inquiry)
- [過去の通信](/letters)
```

### 🖼️ 画像の埋め込み

```markdown
# イベントの様子

![昨年の秋祭りの様子](/img/2024_autumn_festival.jpg)

前回は300名を超える方にご参加いただきました！
```

## 📊 お知らせ管理のベストプラクティス

### ⏰ 投稿タイミング

```mermaid
gantt
    title お知らせ投稿のタイミング例
    dateFormat  YYYY-MM-DD
    section イベント準備
    事前告知        :2025-09-01, 2025-09-15
    詳細案内        :2025-09-15, 2025-10-01
    section イベント実施
    直前リマインダー  :2025-10-18, 2025-10-20
    当日案内        :2025-10-20, 2025-10-20
    section フォローアップ
    結果報告        :2025-10-21, 2025-10-25
```

| フェーズ | タイミング | 内容 | type |
|----------|------------|------|------|
| 📢 **事前告知** | 2-3週間前 | 日時・概要 | `tip` |
| 📋 **詳細案内** | 1週間前 | 詳細・準備事項 | `info` |
| ⏰ **リマインダー** | 前日 | 最終確認 | `warning` |
| 📝 **結果報告** | 開催後 | 活動報告・感謝 | `tip` |

### 🏷️ 効果的なタイトル

**良いタイトル例**:
```
✅ "10/20 秋祭り開催のお知らせ"       # 日付＋内容
✅ "緊急：台風による夏祭り中止"       # 緊急度明示
✅ "会員募集中！一緒に活動しませんか" # 行動呼びかけ
```

**避けるべきタイトル**:
```
❌ "お知らせ"                      # 内容不明
❌ "重要"                          # 具体性なし
❌ "イベントについて"               # 曖昧
```

## 🔍 よくある質問と解決方法

### ❓ Q: お知らせが表示されない

**A: 以下を確認してください**

```mermaid
flowchart TD
    A[お知らせが表示されない] --> B{ファイル名は正しい?}
    B -->|No| C[YYYYMMDD_*.md 形式に修正]
    B -->|Yes| D{YAMLは正しい?}
    D -->|No| E[YAMLフロントマター確認]
    D -->|Yes| F{visible設定は?}
    F -->|false| G[visible: true に変更]
    F -->|true| H{GitHubに反映済み?}
    H -->|No| I[git push を実行]
    H -->|Yes| J[キャッシュクリア<br/>強制再読み込み]
```

### ❓ Q: 順序を変更したい

**A: 以下の方法で制御できます**

1. **日付で制御**（推奨）
   ```yaml
   date: 2025-09-16  # より新しい日付を設定
   ```

2. **優先度で制御**（同日内のみ）
   ```yaml
   date: 2025-09-15
   priority: 1       # 数字が小さいほど上位
   ```

### ❓ Q: 一時的に非表示にしたい

**A: visible設定を使用**
```yaml
---
date: 2025-09-15
title: "準備中のお知らせ"
visible: false    # 一覧では非表示
---
```

### ❓ Q: 緊急のお知らせを目立たせたい

**A: typeとpriorityを調整**
```yaml
---
date: 2025-09-15
title: "緊急：台風による影響について"
type: "danger"    # 赤色で強調
priority: 1       # 最優先表示
---
```
