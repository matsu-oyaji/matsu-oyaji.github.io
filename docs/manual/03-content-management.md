## 📁 ファイル構成の理解

```mermaid
graph TD
    A[ウェブサイト] --> B[📄 ページファイル<br/>.md]
    A --> C[🖼️ 画像・資料<br/>public/]
```

## 📝 ページ編集の実践

### 🏠 トップページの編集

**ファイル**: `index.md`

**編集手順**:
1. VS Code で `index.md` を開く
2. 内容を編集
3. `Ctrl + S` で保存
4. ローカルサーバーで確認

**編集例**:
```markdown
---
layout: home
title: 松ケ丘小学校おやじの会
---

# 松ケ丘小学校おやじの会へようこそ！

## 🎯 私たちの活動

松ケ丘小学校の子どもたちの笑顔のために、
お父さんたちが協力して楽しい活動を企画・運営しています。

### 主な活動内容

- 🎪 **学校イベントのお手伝い**
  - 運動会の設営・片付け
  - 文化祭のサポート

- 🔧 **学校環境の整備**
  - 校庭の草刈り
  - 遊具のメンテナンス
```

## 🖼️ 画像の管理

### 📁 画像保存場所

```
public/
├── img/          🖼️ 一般的な画像
├── event/        🎪 イベント関連画像・資料
├── letter/       📰 おやじの会通信（PDF）
└── docs/         📋 会則・議事録（PDF）
```

### 📐 画像の最適化

**推奨設定**:

```mermaid
graph LR
    A[📷 元画像] --> B[🔧 リサイズ]
    B --> C[🗜️ 圧縮]
    C --> D[✅ 最適化完了]
    
    B1[幅: 1200px以下] --> B
    C1[容量: 500KB以下] --> C
    
    style A fill:#ffe6e6
    style D fill:#e6ffe6
```

| 項目 | 推奨値 | 理由 |
|------|-------|------|
| **幅** | 1200px以下 | ページ表示速度 |
| **容量** | 500KB以下 | 読み込み時間短縮 |
| **形式** | JPG（写真）<br/>PNG（ロゴ・図） | 用途に応じた最適化 |

### 🛠️ 画像圧縮ツール

**オンラインツール（簡単）**:
1. **TinyPNG**: https://tinypng.com/
   - PNG・JPG両対応
   - ドラッグ&ドロップで簡単

2. **Squoosh**: https://squoosh.app/
   - Google製
   - 詳細設定可能

**使用手順**:
1. 上記サイトにアクセス
2. 画像ファイルをドラッグ&ドロップ
3. 圧縮後の画像をダウンロード
4. `public/img/` に保存

### 🖼️ 画像の追加手順

**手順**:
1. **画像を準備**
   - サイズ・容量を最適化
   - ファイル名を半角英数字に変更（例：`2025_summer_event.jpg`）

2. **適切なフォルダに保存**
   ```
   public/img/2025_summer_event.jpg
   ```

3. **マークダウンで表示**
   ```markdown
   ![2025年夏イベントの様子](/img/2025_summer_event.jpg)
   ```

4. **プレビュー確認**
   - ローカルサーバーで表示確認

### 🚫 避けるべきファイル名

❌ **悪い例**:
```
夏祭り 2025.jpg          # 日本語・空白
summer festival.png      # 空白
イベント写真.jpeg        # 日本語
photo(1).jpg            # 括弧
```

✅ **良い例**:
```
2025_summer_festival.jpg
summer_event_photo.png
oyaji_meeting_2025.jpg
activity_photo_01.jpg
```

## 💾 変更の保存とアップロード

### 🔄 基本ワークフロー

```mermaid
flowchart TD
    A[📝 ファイル編集] --> B[💾 ローカル保存]
    B --> C[👀 プレビュー確認]
    C --> D{内容OK?}
    D -->|No| A
    D -->|Yes| E[📦 コミット準備]
    E --> F[💬 変更内容を説明]
    F --> G[⬆️ GitHubにプッシュ]
    G --> H[🤖 自動デプロイ]
    H --> I[🌐 サイト更新完了]
    
    style A fill:#ffe6e6
    style I fill:#e6ffe6
    style D fill:#fff3e0
```

### 🐙 GitHub Desktop での操作

**手順**:
1. **GitHub Desktop を開く**
2. **変更ファイルを確認**
   - 左側に変更されたファイル一覧が表示
3. **変更内容を記述**
   - 下部の「Summary」に簡潔な説明を入力
   - 例：「おやじの会通信Vol.4を追加」
4. **コミット実行**
   - 「Commit to main」をクリック
5. **プッシュ実行**
   - 「Push origin」をクリック

### 💬 良いコミットメッセージの例

✅ **良い例**:
```
おやじの会通信Vol.4を追加
トップページの活動予定を更新
夏祭りイベント写真を追加
会則の誤字を修正
```

❌ **悪い例**:
```
更新
変更
修正
ファイル追加
```

### 🔍 VS Code での操作

**手順**:
1. **Source Control パネルを開く**
   - `Ctrl + Shift + G` (Windows) / `Cmd + Shift + G` (Mac)
2. **変更をステージング**
   - ファイル名の右側「+」をクリック
3. **コミットメッセージを入力**
   - 上部のテキストボックスに説明を記入
4. **コミット実行**
   - `Ctrl + Enter` (Windows) / `Cmd + Enter` (Mac)
5. **プッシュ実行**
   - 「...」メニュー → 「Push」

## 🆘 よくある問題と解決方法

### ❌ 画像が表示されない

**原因と解決方法**:
```mermaid
flowchart TD
    A[画像が表示されない] --> B{ファイルパスは正しい?}
    B -->|No| C[パスを修正<br/>例: /img/photo.jpg]
    B -->|Yes| D{ファイルは存在する?}
    D -->|No| E[public/フォルダに<br/>ファイルを配置]
    D -->|Yes| F{ファイル名は正しい?}
    F -->|No| G[半角英数字に<br/>ファイル名変更]
    F -->|Yes| H[ブラウザの<br/>キャッシュクリア]
```

### ❌ プレビューでエラーが出る

**よくあるエラーと解決方法**:

| エラー内容 | 原因 | 解決方法 |
|-----------|------|----------|
| `Failed to resolve import` | ファイルパス間違い | パスを確認・修正 |
| `Unexpected token` | マークダウン記法エラー | 記法を確認・修正 |
| `File not found` | ファイルが存在しない | ファイルの配置確認 |

### ❌ GitHubにプッシュできない

**解決方法**:
1. **権限確認**
   - GitHub アカウントが正しいか確認
   - リポジトリへのアクセス権限があるか確認

2. **競合解決**
   ```bash
   git pull origin main  # 最新版を取得
   # 競合があれば手動で解決
   git push origin main  # 再度プッシュ
   ```
