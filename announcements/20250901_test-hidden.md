# 非表示テスト用お知らせ

これは表示・非表示機能をテストするためのお知らせです。

<!-- more -->

このお知らせは `visible: false` が設定されているため、トップページやお知らせ一覧には表示されませんが、直接URLにアクセスすることで閲覧可能です。

## 用途例

- 過去のお知らせで現在は無効な内容
- 実装例やテスト用のページ
- 準備中のお知らせ（公開前の段階）
- アーカイブされた情報

## 表示制御の仕組み

フロントマターに以下のように設定：

```yaml
visible: false  # トップ・一覧で非表示
# visible: true   # デフォルト（省略可）
```

個別ページは常にアクセス可能です。
